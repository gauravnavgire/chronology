# Examples

Worked inputs and outputs, all generated by `scripts/chronology.py`.

| Folder / files | Shows |
|---|---|
| `apollo11-notes.md`, `apollo11-events.json`, `output-*` | One source in every layout: tree, timeline, table, bullets, mermaid, csv, json, density, html (`output-html-day.html`) |
| `multi-source/` | Three sources merged: corroboration, a ⚠ conflict, the consistency report, lanes by source, questions (`output-questions.md`), `chronology.html` |
| `calendars/` | Julian, Hijri, Hebrew, Japanese-era, regnal and fiscal dates, and an unsupported Chinese date |
| `story/` | Telling order vs. story order: flashbacks, a flash-forward, linearity |
| `incremental/` | Two runs with a state file: what changed between them |
| `presets/` | The `project` preset (planned vs. actual) and the `incident` preset, confidence scores, an `--as-of` question |
| `tables/` | `orders.csv` (day-first dates), `app-log.csv` (epoch ms, `--collapse`), `support.db` (SQLite, offsets) |
| `exports/` | `.ics` calendars, a Mermaid Gantt chart, TimelineJS and vis-timeline JSON |
| `verify/` | Self-check: a source text with page breaks, and events with four planted errors |
